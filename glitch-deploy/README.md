# نظام تسجيل المواد لجامعة الحضارة

نظام تسجيل المواد لجامعة الحضارة هو تطبيق ويب يسمح للطلاب بتسجيل المواد الدراسية وللمشرفين بإدارة المواد والطلاب والتخصصات.

## الميزات

- تسجيل دخول الطلاب والمشرفين
- تسجيل الطلاب في المواد الدراسية
- إدارة المواد والتخصصات
- إدارة متطلبات المواد
- عرض إحصائيات التسجيل
- واجهة مستخدم متجاوبة مع الأجهزة المحمولة

## التقنيات المستخدمة

- Node.js
- Express.js
- SQLite3
- HTML/CSS/JavaScript
- Bootstrap 5

## كيفية التشغيل

1. قم بتثبيت التبعيات: `npm install`
2. قم بتشغيل الخادم: `npm start`
3. افتح المتصفح على العنوان: `http://localhost:3000`
